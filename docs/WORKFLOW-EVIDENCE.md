## Scope of the evidence

**Established:** these underlying workflows have produced real media in configured working environments. Local generation and Blender execution are not merely theoretical or planned.

**Still to qualify:** a fresh recipient installation of this exact portable package, its generic provider client against real endpoints, discovery inside each coding harness, and reproduction on other hardware. A prior successful custom runner does not automatically validate a newly generalized adapter.

The existing source workflows used environment-specific orchestration. The distributable skills preserve their production methods while moving endpoints, model selection and credentials into user-controlled configuration. The new public sample demonstrates a cloud image route; a new synthetic video example would improve the public showcase, but is not needed to establish that historical video generation occurred.

## Privacy and publication

This summary deliberately omits source-project names, local paths, host details, private prompts and source-file hashes. Original media, transcripts, technical claims and production logs remain outside this distribution. Inspect individual assets and their provenance before selecting public examples; existence of a video is not permission to publish its contents.
