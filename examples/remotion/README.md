# Editable composition starter

A 12-second text-only composition with frame-based motion. It demonstrates native overlays, not the final mix of generated footage and narration.

```sh
cd examples/remotion
npm install
npm run still
npm run render
```

The three beat objects are the source for exact copy. Add your clean footage and separate narration per beat using Remotion media/sequence components; keep timings in frame units. Inspect the still and MP4 before delivery. Dependency versions match the reviewed local version baseline; the lockfile records the resolved package tree. Remotion has its own licensing terms.
